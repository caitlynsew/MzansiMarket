# MzansiMarket
Project Name: MzansiMarket

Description:
MzansiMarket is a Consumer-to-Consumer (C2C) e-commerce platform designed to support South African informal traders and entrepreneurs. The platform enables buyers and sellers to trade securely through verified user accounts, product listings, order management, reviews, wishlists, and dispute handling.

Technologies Used:
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

Features:
- Buyer accounts
- Seller accounts
- Admin dashboard
- Product management
- Shopping cart
- Checkout system
- Order management
- Seller verification
- Wishlist
- Reviews
- Dispute management
